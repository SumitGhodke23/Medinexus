# Deploy medinexusai

## Render

1. Push this project to GitHub.
2. Create a Render account and choose **New > Blueprint**.
3. Select the repository and deploy `render.yaml`.
4. After deployment, open the generated `https://...onrender.com` URL.
5. Create an admin account from Render's shell:

```powershell
python manage.py createsuperuser
```

The blueprint installs dependencies, collects static files, runs migrations, starts Gunicorn, and provisions PostgreSQL.

## Required production settings

The deployment reads these environment variables:

- `DJANGO_SECRET_KEY`: generated by Render in the blueprint.
- `DJANGO_DEBUG`: set to `False`.
- `DJANGO_ALLOWED_HOSTS`: the deployed host, such as `.onrender.com`.
- `DATABASE_URL`: PostgreSQL connection string supplied by Render.
- `CSRF_TRUSTED_ORIGINS`: set to the exact HTTPS URL, for example `https://medinexusai.onrender.com`.

## Local development

Without these variables, the project keeps using the local `db_dev.sqlite3` database:

```powershell
python manage.py migrate
python manage.py runserver
```

The local database is not automatically copied to production. Create production users and data after deployment, or export/import them separately.
